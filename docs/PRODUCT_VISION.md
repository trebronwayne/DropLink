# Product Vision

## Summary
DropLink is a Wi-Fi-first, federated personal-server platform. A phone or computer running DropLink can host services and consume services hosted by other trusted nodes.

## Product promise
**Your phone. Your server. Your network.**

## What DropLink is
- A network of independently owned nodes.
- A service platform, not only a file-transfer tool.
- Offline-first for local services.
- Multi-client: Android, desktop and browser.
- Extensible through independently registered services.

## What DropLink is not
- Not a clone of a single-purpose file-sharing app.
- Not a cloud account requirement.
- Not unrestricted remote access to a phone.
- Not a promise that all Android devices support every Wi-Fi topology.

## Core user journeys
1. Start a local server.
2. Discover and securely pair with another node.
3. Join nodes into a logical network.
4. Browse a unified index of authorized files while preserving each file's owner.
5. Select a specific node for node-specific services such as its camera.
6. Use an authorized internet gateway through supported client features.

## Product principles
- Owner-controlled resources.
- Explicit consent for every sensitive service.
- Clear online/offline status.
- Transport-independent service APIs.
- Graceful behavior when nodes disconnect.
- Transparent network activity and permissions.
